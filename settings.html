테마

라이트/다크는 CRT 효과 없는 깔끔한 화면, 네온은 기존의 레트로 터미널 화면입니다.
THEME MODE / 테마 모드
MOD THEMES / 모드 테마
THEME TEMPLATE / 테마 템플릿
지금 테마의 색이 채워진 테마 파일을 받습니다. id · name과 색을 바꾼 뒤 데스크톱 앱의 모드 폴더에 폴더째 넣으면 "모드 테마"에 나타납니다.

기타 설정

SAVE FOLDER / 저장 위치
세이브는 앱 안이 아니라 이 폴더에 세이브마다 "이름.hemi" 파일로 저장됩니다 — 그대로 백업 · 복사하거나 다른 기기에서 "불러오기"로 열 수 있어요. 탐색기에서 넣은 .hemi 파일은 다음에 시작 화면을 열 때 세이브로 보이고, 게임에서 지운 세이브는 휴지통으로 갑니다. 위치를 바꾸면 지금 세이브가 새 폴더로 옮겨져요. (Program Files처럼 관리자 권한이 필요한 폴더는 쓸 수 없어요)
UPDATE / 업데이트
새 버전이 GitHub Release에 올라오면 반드시 업데이트해야 합니다 — 설치판은 자동으로 받아 저장 후 다시 시작해 설치하고, 업데이트 전까지는 앱을 쓸 수 없습니다.
DEVELOPER MODE / 개발자 모드
개발자 코드를 넣으면 다음 업데이트 미리보기(티저) 화면을 열 수 있습니다.
DEBUG MODE / 디버그 모드
숨겨진 정부 형태
보이기를 고르면 내각 › 내각 설정의 정부 형태 아래에 쿠데타 · 혁명 · 왕정복고로만 들어가던 숨겨진 정부 형태(1.6.2 군정 · 1.6.3 당-국가 체제 · 1.6.6 전제군주정)가 나와 바로 바꿀 수 있습니다. 전제군주정은 그 기능이 들어간 미리보기(티저) 화면에서만 보입니다.
