테마

라이트/다크는 CRT 효과 없는 깔끔한 화면, 네온은 기존의 레트로 터미널 화면입니다.
THEME MODE / 테마 모드
MOD THEMES / 모드 테마
THEME TEMPLATE / 테마 템플릿
지금 테마의 색이 채워진 테마 파일을 받습니다. id · name과 색을 바꾼 뒤 데스크톱 앱의 모드 폴더에 폴더째 넣으면 "모드 테마"에 나타납니다.
THEME COLOR / 테마 색
네온 모드의 강조 색(테두리·글자 등)에 적용됩니다

화면

창 표시와 화면 요소를 고릅니다.
WINDOW / 창 표시
F11 키로 전체 화면과 창 모드를 오갈 수 있습니다
RESOLUTION / 해상도
EXECUTE / 실행 버튼
편집 패널 아래의 "PROTOCOL EXECUTE"(실행) 버튼입니다. 설정을 바꾸면 의석 화면이 알아서 다시 그려져서 기본으로 숨겨 둡니다. 숨겨도 입력 칸 밖에서 Enter를 누르면 다시 그려요.
VOTE / 표결 연출
기존: 좌석에 찬성 · 반대 · 기권을 바로 찍고 "표결 확정"으로 끝냅니다. 개편: 좌석 · 당론으로 예정 표를 정해 두고 "표결 시작"을 누르면 의원들이 무작위 타이밍으로 하나씩 투표한 뒤 찬성 · 반대 · 기권 순으로 자리가 모입니다.
COUNT / 개표 연출
개표하는 동안 반원의 의석을 정당 순서대로 왼쪽부터 채울지, 최종 자리 배치에서 무작위 순서로 켤지 고릅니다 (선거 › 설정에서도 바꿀 수 있어요).
TOOLTIP / 네온 말풍선 색
네온 테마에서 회색 버튼 · 글자에 마우스를 올렸을 때 뜨는 말풍선의 색입니다. 색이 있는 버튼(입법 · 선거 등)의 말풍선은 언제나 그 버튼 색을 따릅니다.

기타 설정

그 밖의 설정입니다.
SAVE FOLDER / 저장 위치
세이브는 앱 안이 아니라 이 폴더에 세이브마다 "이름.hemi" 파일로 저장됩니다 — 그대로 백업 · 복사하거나 다른 기기에서 "불러오기"로 열 수 있어요. 탐색기에서 넣은 .hemi 파일은 다음에 시작 화면을 열 때 세이브로 보이고, 게임에서 지운 세이브는 휴지통으로 갑니다. 위치를 바꾸면 지금 세이브가 새 폴더로 옮겨져요. (Program Files처럼 관리자 권한이 필요한 폴더는 쓸 수 없어요)
DEVELOPER MODE / 개발자 모드
개발자 코드를 넣으면 다음 업데이트 미리보기(티저) 화면을 열 수 있습니다.
DEBUG MODE / 디버그 모드
숨겨진 정부 형태
보이기를 고르면 내각 › 정부 형태 · 권한의 정부 형태 아래에 쿠데타 · 혁명 · 왕정복고로만 들어가던 숨겨진 정부 형태(1.6.2 군정 · 1.6.3 당-국가 체제 · 1.6.6 전제군주정)가 나와 바로 바꿀 수 있습니다. 전제군주정은 그 기능이 들어간 미리보기(티저) 화면에서만 보입니다.
진행 방식
턴제에서는 날짜 줄의 버튼으로 날짜를 넘깁니다. 실시간에서는 날짜를 정한 뒤 진행/일시정지 · 1~5단계 속도를 사용하세요 (Space 전환). 이벤트·설정 확인 중에는 멈추며 불러오면 일시정지합니다. 시나리오는 제작자가 지정한 진행 방식을 따릅니다.
