# DATANET: PARLIAMENT SIMULATION

> 레트로 CRT 터미널 스타일의 의회 시뮬레이터 — 정당·연정·의석 구성, 입법·표결, 선거를 브라우저에서 직접 운영합니다.

---

## 개요

DATANET Parliament Simulation은 설치나 빌드 없이 **브라우저에서 바로 실행**되는 의회 시뮬레이션 도구입니다.

- 단원제 / 양원제 / 삼원제 자유 전환
- 이념 스펙트럼에 따른 정당·연정 구성, 무소속 개별 의원 관리
- 법안 작성 → 상정 → 표결 → 개정안까지 이어지는 입법 절차
- 지역구·비례대표를 혼합할 수 있는 선거 시뮬레이션과 기록 보관
- 전체 상태를 `.json`으로 저장/불러오기

한국어 버전과 영어 버전이 나란히 제공되며, 두 버전은 완전히 동일한 저장 파일 형식을 사용합니다.

## 실행 방법

| 파일 | 설명 |
|------|------|
| `index.html` | 시작 메뉴 (버전 정보, 로드맵 링크, 시뮬레이터 실행) |
| `dno.kr.html` | 시뮬레이터 한국어 버전 |
| `dno.en.html` | 시뮬레이터 영어 버전 |
| `dno.roadmap.html` | 개발 로드맵 및 업데이트 내역 |
| `dno.pre.html` | 과거 프리릴리스 빌드 (개발 중단, 참고용) |

`index.html` 또는 `dno.kr.html`/`dno.en.html`을 브라우저에서 직접 열면 됩니다. Chrome, Firefox, Edge 최신 버전에서 동작하며, 최초 실행 시 픽셀 폰트를 외부 CDN(Google Fonts / jsDelivr)에서 불러오므로 인터넷 연결이 필요합니다.

## 화면 구성

화면은 좌측 **컨트롤 패널**과 우측 **의석 시각화 패널**로 나뉩니다.

- 좌측 상단에서 **의회 형태**(단원제 / 양원제 / 삼원제)를 고르면 전체 UI가 그에 맞춰 재구성됩니다.
- `집권 세력 강조` 체크박스: 켜면 집권 세력(정당 또는 연정) 소속 의석에 금색 글로우 테두리가 표시됩니다.
- `저장 시 사진 포함` 체크박스: 당수·연정 대표 사진까지 저장 파일에 포함할지 선택합니다.
- 하단의 **`>> PROTOCOL EXECUTE <<`** 버튼으로 언제든 강제로 다시 그리고 통계를 갱신할 수 있습니다.
- 컨트롤 패널은 **정당 / 의회 / 입법 / 선거**, 네 개의 메인 탭으로 구성됩니다.

## 🏛 정당 탭

| 하위 탭 | 기능 |
|---|---|
| **이념** | 좌우 스펙트럼 상의 이념을 추가·삭제·드래그로 순서 변경. 정당은 기본적으로 이 순서를 따라 자동 정렬됩니다. |
| **정당** | 정당 이름·색상·로고·설명 편집(내부 탭 "정당"), 각 정당에 **파벌**을 추가해 파벌별 이름·색상·의석 배분 가능. 당수 이름·사진 편집(내부 탭 "당수"). |
| **연정** | 각 연정의 대표 이름·사진을 편집(의석 배정 자체는 "의회 > 연정" 탭에서 진행). |
| **무소속** | 하원/상원/삼원별로 무소속 의석 각각에 이름·사진·이념을 개별 지정. |

## ⚙ 의회 탭

| 하위 탭 | 기능 |
|---|---|
| **설정** | 의원실(하원/상원/삼원) 이름과 총 의석 수 지정, 정당별 이름·색상·의석 수·이념 설정. ▲▼ 버튼으로 정당 순서 수동 변경 가능하며, 수동 정렬 중에는 `↺ 자동정렬` 버튼으로 이념 순 복귀. 하원·상원·삼원 참여 여부는 의원실별로 독립 설정됩니다. |
| **연정** | 여러 정당을 묶어 연정을 구성(체크박스로 멤버 지정), **각외협력**(정식 참여 없이 신임·예산 등에서만 정부를 지지하는 정당) 명칭과 대상 지정, 대표당·집권 세력 지정. "무소속" 탭에서 개별 배정된 무소속 의원은 이름(또는 좌석번호)으로 별도 표시됩니다. |
| **의원** | 지역구 선거로 당선된 의원 개인의 이름·궐석 여부 등을 관리합니다. |
| **무소속** | 개별 무소속 의원을 특정 연정의 **정식 멤버** 또는 **각외협력**으로 배정합니다(소속 없음도 선택 가능). |

집권 세력 의석은 캔버스에서 금색 실선, 각외협력 의석은 금색 점선으로 강조 표시됩니다.

## ⚖ 입법 탭

| 하위 탭 | 기능 |
|---|---|
| **제출** | 법안 제목·내용·태그를 작성하고 가결 기준(과반 / 특별다수 2·3 / 전원일치 / 직접 지정 n분의 m)을 설정해 등록. 등록된 법안은 "기존 법안 수정"에서 상정 전까지 다시 고칠 수 있습니다. |
| **상정** | 대기 중인 법안 목록을 검색·태그 필터로 조회하고, 표결에 올릴 법안을 선택합니다. |
| **표결** | 심의할 법안을 고른 뒤 투표 입력 모드(찬성/반대/기권/제거 또는 좌석 정보 보기)를 선택해 캔버스에서 좌석을 클릭하거나, 정당 일괄 투표로 한 정당 전체에 한 번에 적용합니다. 하원 표결을 확정해야 상원이, 상원(또는 하원)을 확정해야 삼원이 열리며, 앞 단계가 부결되면 다음 단계는 자동으로 **미상정** 처리됩니다. |
| **기록** | 가결·부결이 완료된 법안 아카이브(최신순). 가결은 초록, 부결은 빨간 테두리로 표시되며, "▾ 세부 기록" 토글을 열면 의원실별 표결 결과가 실제 표결 화면과 동일한 막대그래프(가결선 포함)로 재현됩니다. **가결된 법안은 "📝 개정안 발의" 버튼으로 개정안을 작성할 수 있고**, 개정안에는 원본 대비 버전 번호(제n판)가 부여되며 원본 법안 카드에서 딸린 개정안 목록도 함께 확인할 수 있습니다. |

### 양원제 표결 흐름

```
법안 제출
    │
    ▼
하원 표결 ──── 부결 ──▶ 상원 미상정 → 최종 부결
    │
   가결
    │
    ▼
상원 표결 ──── 부결 ──▶ 최종 부결
    │
   가결
    │
    ▼
  최종 가결
```

삼원제에서는 상원(또는 양원제가 아니면 하원) 가결 뒤 삼원 표결이 이어지며, 같은 규칙으로 앞 단계 부결 시 이후 단계는 미상정 처리됩니다.

## 🗳 선거 탭

| 하위 탭 | 기능 |
|---|---|
| **지역구** | 헥스 그리드 위에 지역구를 그리거나 지우고, 이름을 지정합니다. 하원/상원/삼원별로 독립적으로 구성할 수 있습니다. |
| **성향** | 지역구별 특정 정당 지지 성향(가중치)을 칠해 지역 편차를 반영합니다. |
| **선거** | 정당별 지지율(%)과 오차 범위를 입력하고, 비례대표 / 지역구 / 혼합 방식 중 선택해 개표를 실행합니다. 무당파 지지층은 매 선거마다 무작위 비율로 정당에 배분되어 결과에 변동을 줍니다. 보궐선거(궐석 지역구만 재선거)도 지원합니다. |
| **기록** | 개표가 끝나면 자동으로 기록이 저장됩니다. 각 기록은 정당별 의석 요약과 함께 "▾ 세부 기록" 토글로 정당별 실제 득표율(개표에 실제로 반영된 가중치 기준)과 저장 시각을 확인할 수 있고, `↻ 의회 반영`으로 해당 결과를 의회에 즉시 적용하거나 `👁 보기`로 결과만 다시 열람할 수 있습니다. |

## 🖥 캔버스 조작

- 반원형(또는 지역구 지도) 배치도 위에 정당 색상의 점(좌석)이 표시됩니다. 점 테두리는 정당/연정/집권 세력 색, 점 내부는 표결 시 투표 상태 색입니다.
- **좌석에 마우스를 올리면** 흰색 고리가 좌석과 살짝 떨어진 위치에 나타나 클릭 가능한 좌석임을 표시합니다(토성 고리 스타일).
- **좌석을 클릭하면**
  - 입법 탭의 "표결" 화면이면서 투표 입력 모드(찬성/반대/기권/제거)가 선택되어 있을 때 → 해당 좌석에 투표가 입력됩니다. 같은 모드로 다시 클릭하면 초기화됩니다.
  - 그 외의 모든 경우(다른 탭에 있을 때, 또는 표결 화면에서 "🔍 정보 보기" 모드일 때) → **좌석 정보 카드**가 클릭 위치 근처에 뜹니다. 무소속이면 이름(또는 `#좌석번호`), 소속 정당이 있으면 "좌석 정보 #n"이 제목으로 표시되고, 집권 세력이면 제목 앞에 ★가 붙습니다. 본문에는 정당·파벌(있는 경우)·이념·연정·투표 상태가 표시됩니다.
- 정보 카드와 툴팁은 화면 오른쪽/아래 끝에서도 잘리지 않도록 항상 화면 안쪽으로 위치가 보정됩니다.
- 창 크기를 바꾸면 캔버스가 자동으로 다시 그려집니다.

## 저장 / 불러오기

**SAVE** 버튼을 누르면 현재 상태 전체를 `.json` 파일로 저장합니다.

저장 항목:
- 단원제·양원제·삼원제 설정 및 각 의원실 이름·총 의석 수
- 이념·정당(파벌 포함)·연정(각외협력·개별 무소속 배정 포함) 전체
- 정당 정렬 모드(자동/수동)
- 법안 전체, 버전/개정 관계, 의원실별 세부 표결 기록
- 지역구·성향 데이터와 선거 기록
- 현재 투표 입력 상태와 열려 있던 탭 위치

**LOAD** 버튼으로 저장 파일을 불러옵니다. 한국어 버전과 영어 버전은 저장 파일이 완전히 호환됩니다. 구버전 저장 파일(v1~v11)도 하위 호환으로 불러올 수 있으며, 이후 버전에 새로 추가된 값은 기본값으로 채워집니다.
