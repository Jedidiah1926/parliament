# 세계 지도 (0.3.1 · v1.7.1 개발 중인 부분 표시)

**세계 › 지도**에서 `.hemimap`을 불러오면 오른쪽 **세계 지도**에 구역 모양이 표시됩니다. 선거용 **국가 › 지역구 지도**와 같은 파일 형식을 사용하지만 구역의 국가 배정·색은 별도로 저장하며 의석·선거 결과를 변경하지 않습니다.

1. 맵 메이커에서 원하는 세계지도를 만들고 **지역구 프리셋(.hemimap)**으로 내보냅니다. 지도에 SVG 구역 모양이 있어야 합니다. 구역마다 고유한 키를 유지하세요.
2. **세계 › 지도 › 지도 불러오기**에서 파일을 선택합니다. 압축된 `.hemimap`과 압축하지 않은 JSON 내용 모두 읽습니다.
3. **칠할 국가**를 고르고 **영토 칠하기**로 구역을 누르거나 끕니다. 같은 국가의 여러 구역·섬을 같은 색으로 칠할 수 있습니다. 국가 목록은 **세계 › 국가 순위**와 공유합니다. **국가 추가**로 새 나라를 등록할 수도 있습니다.
4. **구역 확인**은 배정 없이 이름·국가를 보여줍니다. **배정 지우기**는 미배정으로 돌립니다. **실행 취소/다시 실행**은 붓질 한 번을 한 단계로 처리합니다.
5. 휠로 마우스 위치를 기준으로 확대/축소하고 휠 버튼 또는 빈 바탕을 끌어 이동합니다. **전체 보기**로 초기 화면에 돌아갑니다. 지도에 키보드 초점을 두면 방향키·`+`/`-`/`0`을 사용할 수 있고 구역은 Enter로 조작할 수 있습니다.
6. **내보내기**는 같은 `.hemimap` 형식에 세계지도 배정 정보를 함께 담습니다. 다른 세이브로 불러올 때 빠진 국가는 복원하고, 이미 있는 같은 ID·이름의 국가에 연결합니다. 내보낸 사람의 플레이 국가와 현재 플레이 국가가 다르면, 원래 국가의 영토를 현재 플레이 국가로 바꾸지 않고 별도 국가로 유지합니다.

세계지도는 각 게임 세이브의 `worldMap`에 저장됩니다. 지도 없는 이전 세이브를 열면 다른 세이브의 세계지도를 가져오지 않습니다. 시나리오에서 사용하려면 세계지도를 배정한 게임을 `.hemi`로 저장하고 시나리오 메이커의 **시작 나라 › 세이브 파일**로 선택하세요.

## 파일 호환

기존 `format: "hemicycle-districts"`, `district.svgMap`, 이름·약칭·의석·인구·권역 정보를 유지합니다. 세계 영토 정보만 다음 확장 필드로 담습니다.

```json
"worldMap": {
  "version": 1,
  "countries": [{ "id": "republic", "name": "공화국", "self": false }],
  "owners": { "western_region": "republic", "island": "republic" },
  "colors": { "republic": "#437fa2" }
}
```

맵 메이커에서 이 파일을 다시 편집·내보내도 확장 필드는 유지됩니다. 지운 구역의 배정은 제거되며, 새로 나눈 구역은 세계지도에서 다시 배정합니다. SVG는 허용된 구역 도형·기하 속성으로 다시 구성하므로 이벤트 핸들러나 바깥 그림을 실행하지 않습니다.

## PNG 등 비벡터 지도 분할

맵 메이커에 PNG·WebP·JPEG·BMP 등을 올리면 자동 추적합니다. **픽셀 지도**는 정확히 같은 색으로, 일반 추적은 **색 허용 오차**에 따라 나눕니다. 픽셀 지도에서는 오차 슬라이더를 사용하지 않으며, 일반 추적을 원하면 픽셀 지도를 끄세요.

- 허용 오차를 낮추면 비슷한 색을 나누고, 높이면 비슷한 이웃 색을 묶습니다.
- 슬라이더·최소 크기·바탕 제거·합치기 설정을 바꾼 뒤 조작을 잠시 멈추면 자동으로 다시 추적합니다. 위치·확대는 유지합니다.
- 최신 설정의 결과만 적용합니다. 이전 추적이 늦게 끝나도 최신 결과를 덮지 않고, 파일을 바꾸거나 초기화하면 이전 작업을 취소합니다.
- 추적 실패 시 기존 지도를 유지합니다. 추적 중에는 이전 결과를 내보내지 않도록 내보내기 버튼이 잠시 비활성화됩니다.
- 높은 색 허용 오차가 바탕 제거 기준까지 넓혀 실제 땅을 바다로 삭제하던 계산을 수정했습니다.

검증: `node tests/world-map-data.test.cjs`, 로컬 서버에서 `node tests/world-map.browser.cjs`, `node tests/map-trace.browser.cjs`.

## 경제권 — 지도상의 경제 지역 (개발 중 · v1.7.1)

**세계 › 경제권**에서 세계 지도의 구역을 묶어 ‘북부 공업권’, ‘연안 무역권’, ‘수도 경제권’ 같은 경제 지역을 만듭니다. 국가 영토·선거 지역구와 **별도의 레이어**이고 국경을 넘어도 됩니다.

1. **세계 › 지도**에서 `.hemimap`을 먼저 불러옵니다(경제권은 그 지도의 구역에 배정합니다).
2. **세계 › 경제권**에서 이름을 적고 **경제권 추가**. 고른 경제권의 이름·약칭·색·설명·ID를 고칠 수 있습니다. ID는 시나리오의 경제권 조건·효과가 쓰는 이름입니다(영문·숫자·`_ . -`).
3. **경제권 칠하기**로 구역을 누르거나 끌어 배정합니다. 한 구역은 **경제권 하나 또는 미배정**입니다. **배정 지우기**·**실행 취소/다시 실행**·**모든 배정 지우기**는 경제권 배정에만 작용하고 국가 영토의 실행 취소 기록과 따로입니다.
4. 지도 위의 **국가 영토 / 경제권**으로 표시를 바꿉니다. 경제권을 칠해도 국가 영토는 바뀌지 않고, 영토를 넘겨도 경제권 경계는 그대로입니다.
5. **구역 찾기**에서 이름·키로 찾거나 **미배정만** 골라 볼 수 있습니다. 찾은 구역을 누르면 지도에서 선택됩니다.
6. 경제권을 삭제하면 소속 구역은 미배정이 되고, 그 ID를 쓰는 시나리오 조건·효과는 검사에서 오류가 됩니다.

고른 경제권에는 **구역 수와 소유 국가 분포**를 보여 줍니다. 구역별 인구·생산·산업 자료는 게임에 아직 없으므로 **“자료 없음”**으로 표시합니다 — 나라 전체 지표를 구역 수로 나눈 값을 지역 통계처럼 보여 주지 않고, 경제권을 만들었다는 이유로 GDP·물가를 바꾸지 않습니다. 경제권별 정책·생산·물류는 [메이커 보완 설계](design/SCENARIO_MAKER_EXPANSION.md)의 자원·시설과 함께 만들 예정으로 **아직 없습니다.** 겹치는 경제권·하위 경제권도 지원하지 않습니다.

경제권은 세이브의 `economicRegions`(세계지도의 `worldMap`과 다른 칸)에 저장되고, **내보내기**한 `.hemimap`에도 같은 이름의 확장 필드로 들어갑니다.

```json
"economicRegions": {
  "version": 1,
  "zones": [{ "id": "north", "name": "북부 공업권", "abbr": "북공", "color": "#437fa2", "desc": "" }],
  "regions": { "capital": "north", "riverbank": "north" }
}
```

- 경제권이 없으면 세이브·지도 파일에 이 칸을 만들지 않습니다. 이 칸이 없는 예전 세이브·지도 파일은 경제권 없는 상태로 열립니다.
- 지도에 없는 구역이나 없는 경제권을 가리키는 배정은 읽을 때 버립니다. 경제권이 들어 있지 않은 지도 파일로 바꾸면 경제권 목록은 두고 **배정만 비웁니다**(새 지도의 구역에 옛 배정을 조용히 붙이지 않습니다).
- 맵 메이커에서 다시 편집·내보내도 유지됩니다.

검증: `node --test tests/world-map-data.test.cjs`, 로컬 서버에서 `node tests/economic-regions.browser.cjs`.

## 시나리오와의 연결 (개발 중 · v1.7.1)

시나리오의 방향성·이벤트·결정이 영토와 경제권 배정을 바꾸고 조건으로 읽을 수 있습니다 — 사용법은 [시나리오 › 세계지도 연동](CAMPAIGN.md#세계지도-연동-개발-중--v171--032), 설계는 [시나리오·세계지도 연동 설계](design/SCENARIO_WORLD_INTEGRATION.md).

영토나 경제권 배정이 실제로 바뀌면 지도 화면이 `hemi-world-map-changed` 알림(`detail: { source, keys, layer }`)을 한 번 보냅니다. `source`는 `manual`(붓질·실행 취소·지우기)·`import`(지도 파일)·`script`(시나리오 효과), `layer`는 `owners`(국가 영토)·`zones`(경제권)입니다. 세이브를 여는 것은 알리지 않습니다.
