# 시나리오 0.3.2 · 메이커 확장과 Steam 멀티플레이

- 상태: **예정 · 설계 초안 — 기능 구현 전**
- 계획 정리일: **2026-11-12**
- 대상: **시나리오 v0.3.2**, 전체 게임 **v1.7.1에 포함**
- 현재 구현 버전: 시나리오 `0.3.1`. 이 문서 작성으로 실행 중인 버전이나 빌드 날짜를 바꾸지 않습니다.

지금까지 정리한 계획 중 **시나리오·메이커·멀티플레이 관련 항목을 0.3.2에 모읍니다.** 전체 게임 1.7.1과 시나리오 0.3.2는 서로 다른 버전 체계이며, 같은 업데이트에 포함하는 관계입니다. 아래 내용은 현재 기능 안내나 구현 완료 내역이 아닙니다.

## 2. 플레이 규칙과 보호

제작자는 정당·의석 등을 플레이어가 임의로 고치지 못하도록 항목별로 잠글 수 있게 합니다. 잠금은 **수동 편집과 정상 플레이 명령/시나리오 효과를 구분**합니다. 의석 직접 수정은 차단하되 정해진 선거·이벤트 결과는 반영되어야 합니다.

버튼뿐 아니라 실제 변경 경계에서 목록·드래그·단축키·일괄 편집·상태 병합 등의 진입점을 검사합니다. 차단 사유를 표시하고 부분 변경이나 비용 차감을 남기지 않습니다. 저장/재접속 뒤에도 정책을 유지하고, 멀티에서는 호스트가 참가 국가·행동 권한·시나리오 잠금을 함께 검사합니다.

기존 제작물에 새 설정이 없으면 기존 동작을 유지합니다. 새 제작물에는 권장 잠금 묶음을 제안하고, 제작 중 초기 데이터 편집과 플레이 중 권한을 분리합니다. 가이드/프로 JSON은 같은 정책을 편집해야 합니다.

## 3. Steam 시나리오 멀티 규칙

- **참가:** 같은 시나리오의 서로 다른 국가를 담당합니다. 친구 초대·로비·국가 선택·준비를 제공하고 게임/시나리오/지도/모드 버전과 콘텐츠 일치를 시작 전에 확인합니다. 처음에는 실제 2인 검증부터 하며 최대 인원은 부하 시험으로 정합니다.
- **상태:** 공통 세계 상태·국가별 진행·개인 화면 상태를 나눕니다. 국가는 자기 방향성·결정·연구·경제·군사·자원 등을 별도로 유지합니다. 카메라·확대율·열린 탭은 공통 세계 상태로 덮어쓰지 않습니다.
- **턴제:** 공통 시계에서 참가국 모두 준비하면 하루 진행하고 준비 취소를 지원합니다. 여러 턴 건너뛰기를 추가하지 않습니다.
- **실시간:** 호스트가 배속·재개를 제어하고 참가자는 일시정지할 수 있게 합니다. 대상 국가의 필수 이벤트 선택을 기다리는 동안 공통 시간을 멈춥니다. 정보 기사 열람만으로 방 전체를 멈추지 않습니다.
- **명령:** 호스트가 권한·참조·비용·시각을 검증하고 명령 번호 순서대로 한 번 확정합니다. 난수 결과·연구·생산·거래·영토/경제권 변경을 참가자마다 다시 추첨/계산하지 않습니다.
- **복구:** 누락/중복/역순 명령·체크섬 불일치를 처리하고 필요하면 진행을 멈춰 재동기화합니다. 이탈 시 공통 시간을 멈추고 같은 계정으로 재접속할 수 있게 합니다.
- **저장:** 공통 세계·국가별 진행·참가국 배정·대기 선택·시간·난수 상태/결과·마지막 적용 명령을 복원합니다. 호스트 종료 뒤에는 공통 저장으로 새 방에서 재개하며, 자동 호스트 이전은 첫 구현의 완료 조건에 넣지 않습니다.
- **Steam 기반:** App ID·사용할 SDK/바인딩의 실제 로비/전송 지원·Electron 패키징을 확인합니다. 창작마당 기반이 있다는 이유로 멀티 연결이 구현된 것으로 보지 않습니다. 실제 서로 다른 Steam 계정 2개로 시험하기 전에는 완료로 표시하지 않습니다.

## 4. 공통 실행·검사 기준

모든 운영 모듈은 작성 폼뿐 아니라 초기 상태·플레이 동작·비용/예약/환급·시간 진행·조건/효과·실패 처리·저장/복원·검사·멀티 동기화까지 연결합니다. 기존 국가 경제와 시나리오 계산이 같은 생산/수입을 이중 적용하지 않게 합니다.

오류 검사는 가이드 항목 또는 프로 JSON의 문제 위치로 이동하고, 오류·경고·확인 필요를 구분합니다. 미적용 입력과 확장 필드를 보존합니다. 원본 보관용 저장/내보내기는 가능하게 하고 실행에 필요한 오류가 있으면 시험 플레이/멀티 시작을 막습니다.

성능은 고정 자료와 같은 환경에서 입력/화면 전환 지연·캔버스 프레임·조건/시간 계산·저장/동기화 시간·메모리를 변경 전후 비교합니다. 숫자를 측정하기 전에는 개선 완료로 표시하지 않고, 검사를 없애거나 진행 규칙을 생략해 빨라진 것으로 처리하지 않습니다.
