# v1.7.1 시나리오 메이커 보완 설계

- 상태: **검토용 초안 — 기능 구현 전**
- 대상 릴리스: **v1.7.1** · [통합 작업 계획](V1_7_1_PLAN.md)
- 목적: 방향성·결정·기술·군사·경제·무역·자원을 하나의 시나리오로 제작하고, 플레이 중 허용할 조작을 정하기

이 문서는 추가할 제작 기능과 게임 규칙의 설계입니다. 현재 형식의 이름·확장 필드는 구현 전에 확정합니다. 기존 방향성·이벤트·결정·시간 기능이 있다고 해서 기술 연구·군사 생산·무역 시뮬레이션도 이미 지원하는 것으로 안내하지 않습니다.

## 1. 제작 흐름과 편집 방식

제작자는 **시작 국가와 세계 설정 → 사용할 시스템 선택 → 초기 데이터 → 방향성·결정·이벤트 연결 → 플레이 규칙과 잠금 → 검사 → 시험 플레이** 순서로 작업합니다. 각 기능은 켜고 끌 수 있게 하며, 군사나 자원이 없는 서사 중심 시나리오도 만들 수 있어야 합니다.

가이드에서는 예제·기본값·선택 목록과 필수 입력 위주로 작성합니다. 프로 모드는 같은 데이터를 JSON으로 직접 편집하며, 전환해도 확장 필드·미적용 입력·초안이 사라지지 않아야 합니다. 기존 화면 이름과 네온·라이트·다크 스타일, 스크롤바, 방향성 트리의 확대/축소·휠 버튼 이동을 유지합니다.

화면은 기본 설정·세계/시작 국가·서사·국가 운영·검사로 묶고, 비활성 모듈의 상세 입력은 접어 둡니다. 방향성·기술 트리의 캔버스, 결정 목록, 숫자/표 편집은 각 작업에 맞게 제공합니다. 모든 기능을 한 화면에 펼쳐 놓거나 JSON 입력만으로 제공한 상태를 제작기 완료로 보지 않습니다.

## 2. 제작 가능한 시스템

| 시스템 | 제작자가 정할 데이터와 규칙 | 플레이·다른 시스템과 연결 |
|---|---|---|
| 방향성 | 국가별 트리·분기, 필수/선택 선행·배타 관계, 기간·비용, 노출/시작/지속 조건, 완료/취소 효과, 이미지·명판 | 사건·정책·기술 해금·생산·영토 변경. 기존 방향성 형식과 호환 |
| 결정 | 전용 목록·분류, 대상 국가/경제권, 가시성·실행 조건, 비용·준비 시간·지속 시간·재사용 대기, 일회/반복, 완료/실패/취소 효과 | 예산·자원 차감, 외교·정책·투자·동원·이벤트 연결. 고급 JSON에 숨겨진 항목으로만 두지 않기 |
| 기술 트리 | 기술 분야·연구 노드·선행/배타, 연구 슬롯·기간·비용·진척, 초기 기술, 연구 중지/재개·취소 규칙 | 장비·시설·생산법·정책·결정 해금, 연구 보정. 방향성과 별도 진행 상태 |
| 군사력 | 국가별 병력·예비군·동원, 육/해/공군 및 사용자 정의 병종, 부대/장비 종류·초기 수량, 편제·배치 구역, 준비도·사기·보급 | 모집·훈련·동원·생산/손실·해산, 자원·예산 소모, 기술 요구, 이벤트/결정으로 전력 변화 |
| 경제 | 국가별 초기 예산·수입/지출·부채, 지역 인구/산업, 시설·생산능력·건설·투자, 정책과 계산 주기 | 기존 국가 경제와의 연결 방식 선택, 시설·기술·자원·경제권 효과. 지표와 시뮬레이션 규칙을 구분 |
| 무역 | 거래 상대·품목·수량·단위·가격·통화·기간, 수입/수출, 운송 능력·관세·금수, 수락·중단·만료 조건 | 국가 간 재고/대금 결제, 부족·운송 차질·제재에 따른 처리, 이벤트/결정으로 계약 변경 |
| 자원 | 자원 ID·이름·아이콘·단위, 매장/채굴/생산/소비, 재고·저장 한도, 산지·시설별 배치, 초기 수량 | 생산 투입/산출, 군수·연구·건설 비용, 거래와 부족 효과. 석유·철강·식량 등 제작자가 정의 |
| 세계·경제권 | 국가 ID·영토·지역 이름, 독립적인 경제권 배정, 지역 인구·시설·자원 연결 | 지도에서 초기 상태 편집, 영토 변경과 경제권 변경을 별도로 실행 |
| 외교·국가 관계 | 국가 간 관계·협정·제재, 조건부 행동·제안/응답, 플레이어/자동 운영 국가 지정 | 무역·접근권·군사 동원·이벤트 대상 연결. 국가 관계 변화는 명시적 효과로 처리 |
| 서사·격변·목표 | 기사·선택형 이벤트·격변·임무·승패/결말, 공통 및 국가별 조건, 순서와 중복 발생 규칙 | 정보 전달과 선택 효과 분리, 시간·영토·기술·경제 변화로 발생 |
| 공통 변수·정책 | 국가/세계 범위 변수·플래그, 제한값·수식·보정·지속 기간, 정책 목록과 초기값 | 여러 시스템이 같은 비용·조건·효과 규칙을 사용하고 변경 사유를 추적 |

위 표의 제작 데이터만 넣고 플레이에서 반영되지 않는 항목은 완료가 아닙니다. 각 모듈은 **초기 설정·플레이 조작·시간 진행·조건/효과·저장 복원·검사·멀티 동기화**를 함께 정의합니다. 모듈별 자동 운영은 첫 단계에서 우선순위·조건부 결정·대기 등 명시적 규칙을 사용하고, 사람처럼 판단하는 전략 AI를 이미 제공한다고 가정하지 않습니다.

군사 모듈에는 수치 편집뿐 아니라 모집·장비/보급·손실 등 상태 변화 규칙이 필요합니다. 전투를 지원하는 시나리오에는 참가 부대·대상 지역·기간·판정/손실·종료/영토 효과를 정하고 결과를 재현할 수 있게 합니다. 세부 전선 조작·전술 이동·점령과 소유의 복잡한 분리·고도 전략 AI는 별도 후속 설계로 둡니다. 기본 군사 제작 기능 자체를 후속으로 미루지는 않습니다.

## 3. 데이터·시간·계산 계약

- **정의와 진행 상태 분리:** 자원/기술/부대 종류·비용 규칙은 작성 데이터, 현재 재고·연구 진척·부대 상태·계약은 국가별 실행 데이터로 관리합니다. 초기 데이터 변경과 진행 세이브 변경을 혼동하지 않습니다.
- **국가와 지역 연결:** 국가 논리 키·세계지도 구역 키·경제권 ID를 사용합니다. 표시 이름을 식별자로 삼지 않고, 모든 시작 국가에서 참조와 초기 상태를 검사합니다. 경제권은 지도상의 경제 지역이라는 기존 결정을 유지합니다.
- **비용의 일관성:** 시작 비용·예약 비용·기간별 유지비·취소 환급을 구분합니다. 동시에 연구/모집/거래를 시작해 같은 예산/자원을 중복 지출하지 못하게 합니다. 일괄 효과는 필요한 참조·재고·권한을 먼저 검사합니다.
- **자료와 계산 구분:** 자료만 보여주는 모드와 자동 계산 모드를 명시합니다. 자동 계산을 켜면 산식·단위·생산 한도·부족 시 중단/축소·마이너스 재고 허용 여부를 정합니다. 국고 적자나 부채는 재고 부족과 별도 규칙입니다.
- **기존 경제 연결:** 기존 국가 경제를 쓸지 시나리오 자체 경제 규칙을 쓸지 정하고, 두 시스템이 같은 수입/생산을 각각 더하지 않도록 계산 주체를 하나로 정합니다. 기존 전국 지표로 지역별 자료를 임의 생성하지 않습니다.
- **주기:** 턴제는 한 턴=하루, 실시간은 게임 내 경과 시간으로 누적합니다. 월별 계산은 월 경계에서 한 번만, 시간당/일별 계산은 지정된 경계에서 한 번만 적용합니다. 배속·일시정지·저장/불러오기·재접속으로 생산·유지비·연구가 중복 적용되지 않아야 합니다.
- **무역 결제:** 거래의 공급/운송/대금 조건을 함께 검사하고 체결·결제·중단 순서를 정합니다. 부족한 물량의 부분 이행 여부와 대금 정산, 공통 통화 또는 환율 적용 규칙을 명시합니다. 양쪽 재고·자금 중 한쪽만 바뀌는 실패를 막습니다.
- **결과 표시:** 행동 전에 비용·기간·조건·예상 변화를 보여주고, 완료/실패/차단 이유를 설명합니다. 정의되지 않은 지표는 ‘자료 없음’으로 표시합니다.

## 4. 플레이 중 편집 잠금

**사용자 요청:** 시나리오에서 정당·의석 등을 플레이어가 임의 수정하지 못하도록 제작자가 잠글 수 있게 합니다. 작성 중인 프로젝트의 초기 데이터 편집과 실제 시나리오 플레이의 수동 편집 권한을 분리합니다.

### 잠글 수 있는 항목

| 항목 | 제한할 수동 변경 예 | 계속 허용할 정상 변화 |
|---|---|---|
| 정당 | 생성·삭제·이름·색·이념·합당·분당 직접 수정 | 시나리오가 허용한 창당/분당 결정·이벤트 효과 |
| 의석·의원 | 의석 수·정당 배정·의원/지역구 배치·직접 이동 | 정해진 선거·보궐/이동 규칙·시나리오 효과 |
| 선거·제도 | 선거제도·원의 구성·임기·선거 일정·결과 수동 덮어쓰기 | 시나리오가 허용한 개헌·법안·선거 진행 |
| 정부·정치 | 정부 구성·인사·지지율·여론·정책 수치 강제 수정 | 플레이 규칙에 따른 인사·정책·의회 행동·자동 변화 |
| 세계지도·경제권 | 영토·국가·경제권 배정 수동 칠하기/삭제 | 허용된 협정·방향성·이벤트·경제권 효과 |
| 경제·무역·자원 | 국고·생산·시설·재고·가격·계약을 편집기로 강제 변경 | 예산·생산·건설·거래 등 시나리오에서 제공한 행동 |
| 기술·군사 | 연구 완료 강제 설정·부대/장비/병력 수치 직접 입력 | 연구·모집·생산·동원·허용된 전투/이벤트 결과 |
| 시간·운영 | 허용되지 않은 날짜 건너뛰기·배속·진행 방식 변경 | 시나리오 시간 조작과 멀티 방의 정해진 권한 |

읽기·검색·지도 이동·화면 전환은 가능하게 하고, 잠긴 입력은 이유와 정상적으로 변경할 방법을 보여줍니다. 예: “이 시나리오에서는 의석을 직접 수정할 수 없습니다. 선거 또는 이벤트를 통해 변경됩니다.”

### 제작 화면과 기본값

메이커의 **플레이 규칙**에 권장 잠금 묶음과 항목별 설정을 둡니다. 초보자는 **규칙에 따라 플레이** 묶음으로 정당·의석·핵심 수치 직접 편집을 잠그고, 자유 편집용 시나리오는 필요한 항목을 풀 수 있습니다. 일부 항목만 잠그거나 특정 수동 행동을 허용하는 설정도 제공합니다.

기존 제작물에 설정이 없으면 기존 동작을 유지합니다. 새 제작물에는 권장 잠금값을 제안하고 적용 값을 보여줍니다. 제작자가 프로젝트를 편집할 때는 초기 정당/의석을 작성할 수 있으며, 시험 플레이는 실제 플레이 잠금 규칙을 기본으로 실행합니다. 별도 제작자 진단 실행은 일반 플레이와 구분해 표시합니다.

새 설정의 가칭은 `playRules`이며 **현재 미지원**입니다. 항목별 정책·허용 행동을 가이드와 프로 JSON에서 동일하게 편집합니다. 기존 `campaign` 키·파일 형식의 호환 방식을 확정한 뒤 도입하며, 진행 세이브에는 적용한 정책을 보관합니다.

### 적용 위치

- 버튼 숨김/비활성뿐 아니라 **실제 상태를 바꾸는 공통 명령 경계**에서 검사합니다. 목록·다른 화면·드래그·단축키·일괄 편집 등 다른 진입점도 같은 규칙을 적용합니다.
- 플레이어 직접 편집, 정상 플레이 명령, 승인된 시나리오 효과를 구분합니다. 효과가 기존 내부 편집 함수를 사용해도 출처·대상·행동을 검사하고, 모든 스크립트에 무제한 수정 권한을 주지 않습니다.
- 불러오기·프리셋 적용·상태 병합으로 같은 진행 게임의 잠긴 영역을 덮어쓰는 경로도 검사합니다. 다른 세이브를 여는 동작과 현재 시나리오의 잠금을 해제하는 동작은 구분합니다.
- 멀티에서는 호스트가 참가자의 국가·행동 권한과 시나리오 정책을 함께 검사합니다. 클라이언트에서 잠금 버튼을 없앤 것만으로 권한 검사를 끝내지 않습니다. 방 설정으로 시나리오의 필수 잠금을 임의 완화하지 않습니다.
- 차단된 작업은 부분 변경·자원 차감·사용 기록을 남기지 않습니다. 저장·재접속 뒤에도 잠금이 유지되고, 정책이 누락/불명확한 진행 세이브는 조용히 전부 허용하지 않도록 호환·복원 규칙을 정합니다.

## 5. 모듈 간 연결 예제

**산업화와 국경 위기** 예제를 추가합니다.

1. 경제권 지도에서 북부 공업권을 설정하고 철광석 산지·제철 시설·재고·예산을 입력합니다.
2. 방향성 **산업 기반 확충** 완료로 제철 연구와 투자 결정을 엽니다.
3. 연구 비용을 지불하고 기술 **개량 제철법**을 완료하면 생산법이 해금됩니다.
4. 결정 **제철소 투자**가 예산·건설 기간을 소모하고 철광석을 철강으로 전환합니다.
5. 다른 국가와 철강 무역을 체결하고 공급/대금 부족 때 정한 규칙으로 중단 또는 축소합니다.
6. 철강·예산·인력을 사용해 부대를 모집하고 보급비를 지불합니다. 군사력 변화가 협상 이벤트 조건에 반영됩니다.
7. 협상을 수락하면 영토가 바뀌고 정보 기사가 발행됩니다. 거절하면 별도 격변/결말로 갑니다.
8. 정당·의석·재고 직접 편집을 잠근 상태에서 정상 연구·생산·무역·선거/이벤트 변화는 진행됩니다.

같은 예제를 턴제·실시간·Steam 2인에서 검증합니다. 예제에 사용한 비용·단위·기간·계산식은 제작자가 읽을 수 있게 공개하고, 어느 단계에서 중단·취소·재접속해도 진행 결과가 일치해야 합니다. 이 문서만 작성한 상태에서 예제가 이미 플레이 가능하다고 표기하지 않습니다.
