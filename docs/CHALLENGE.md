# Hemicycle 챌린지 (0.3.0 · 테스트) — 목표 · 실패 조건이 있는 짧은 도전

> 시나리오(세계관 · 방향성 트리 · 격변)는 [CAMPAIGN.md](CAMPAIGN.md).

메인 화면 › **만들기** › **챌린지 메이커**(challenge.html)에서 목표가 있는 챌린지를 만들고, 바로 시험 플레이하고, 파일로 나눕니다.

## 챌린지에 들어가는 것

| 칸 | 뜻 |
|---|---|
| 제목 · 제작자 · 버전 · 한 줄 설명 | 목록 · 브리핑에 보임 |
| 브리핑 | 시작할 때 뜨는 글 (빈 줄로 문단 나눔) |
| 승리 · 패배 글 | 결과 창에 보임 |
| 시작 | 내장 프리셋 하나, 또는 세이브 파일(.hemi) — 게임에서 시작 상황을 만들고 저장 › 파일로 저장 |
| 마감일 | `YYYY-MM-DD`. 그날까지 목표를 다 못 이루면 패배 |
| 마감일까지 버티면 승리 | 켜면 목표를 다 이뤄도 바로 끝나지 않고, 마감일에 목표가 지켜져 있으면 승리 |
| 목표 | 다 이루면 승리. "선택" 목표는 승리에 필요 없음, "끝까지 유지"는 이뤘다가도 다시 깨질 수 있음 |
| 실패 조건 | 하나라도 맞으면 패배 |
| 이벤트 · 결정 · 변수 | 스크립트 모드 형식 — [MODDING.md](MODDING.md). 그 챌린지의 세이브에서만 돎 |

목표 · 실패 조건은 화면에서 고릅니다: 정당 집권 / 집권하지 않음, 정당 의석, 정당 지지율, 집권 세력 의석, 국정 지지율, 경제 지표, 날짜, 정당 상태, 플래그, 챌린지 변수, 또는 **직접 쓰기(JSON)** — 스크립트 모드의 조건을 그대로 씁니다.
정당은 이름 · 약칭으로, 또는 `ruling`(집권 세력 최대 정당) · `largest`(하원 최대 정당) · `opposition`(야당 최대 정당).

목표의 "플래그" · "챌린지 변수"는 이 챌린지의 이벤트 · 결정이 켜는 플래그 · 변수와 이어집니다 — 예: 결정의 효과 `{ "set_flag": "reform_done" }` → 목표 "플래그 reform_done".

## 플레이

- **▶ 시험 플레이** — 시작 상태로 새 세이브를 만들고 챌린지를 붙여 게임을 엽니다. 브리핑 창이 뜨고, 오른쪽 아래 🎯 카드에 목표가 보입니다.
- 날짜를 넘길 때 · 총선 결과를 의회에 반영할 때 목표 · 실패 조건 · 마감일을 검사합니다 (🎯 카드의 "지금 확인"으로도).
- 결과가 나면 승리 · 패배 창 — "계속 플레이"로 그 나라를 이어서 해도 됩니다. "챌린지 끝내기"는 그 세이브에서 챌린지만 뗍니다.
- 챌린지는 그 세이브에 저장되므로, 저장하고 나중에 이어 해도 목표 · 진행이 남습니다.

## 저장 · 공유

- 만든 챌린지는 이 브라우저 · 앱에 자동 저장됩니다 (위쪽 "내 챌린지" 목록).
- **내보내기**는 `.hemichl` 파일(세이브 .hemi처럼 gzip으로 압축한 JSON)로 — 세이브 파일로 시작하는 챌린지는 그 세이브도 함께 담깁니다.
- **불러오기**로 다른 사람의 `.hemichl`을 열면 내 챌린지에 들어갑니다.

## 파일 형식

```json
{
  "format": "hemicycle-challenge@1",
  "id": "scn_...", "title": "...", "author": "...", "version": "1.0", "description": "...",
  "briefing": "...", "winText": "...", "loseText": "...",
  "start": { "kind": "preset", "preset": "builtin:tutorial" },
  "deadline": "1990-12-31", "surviveToDeadline": false,
  "goals":    [{ "id": "g1", "text": "사민당 집권", "condition": { "ruling": "사회민주당" }, "required": true, "hold": false }],
  "failures": [{ "id": "f1", "text": "집권 세력 의석 30% 미만", "condition": { "ruling_seats": { "share": true, "lt": 30 } } }],
  "variables": {}, "events": [], "decisions": []
}
```

`start`는 `{ "kind": "save", "name": "...", "state": { 세이브 전체 } }`일 수도 있습니다. 목표 · 실패 조건의 `kind` · `p`는 편집기 화면용 칸이라 없어도 됩니다 (`condition`만 있으면 됨).
