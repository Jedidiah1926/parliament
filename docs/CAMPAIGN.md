## 시간 (0.3.1)

현재 메인 표시는 **v1.7.0 · v0.3.1 (OBT)**입니다. 1.7.0은 전체 게임, 0.3.1은 시나리오 기능 버전입니다. 아래 시간 기능의 구현 내역은 로드맵 0.3.1에, 다음 시나리오·멀티 계획은 0.3.2에 기록합니다.

제작할 때 **기본 · 세계관 › 시나리오 시간**에서 진행 방식을 고릅니다. 시나리오의 날짜·시각·턴·속도는 `campaign.clock`에 따로 저장합니다. 국가 날짜는 기존 경제·여론·회기 기능과 연동하기 위해 이 날짜를 표시하며, 직접 편집과 일반 날짜 건너뛰기는 막습니다.

- **턴제**: 현재 1턴=1일입니다. **다음 턴** 한 번에 한 턴만 진행합니다. 방향성 기간·임무 기한은 턴으로 표시하며, JSON의 기존 `days` 필드는 유지합니다.
- **실시간**: 1시간씩 진행합니다. **진행/일시정지**, **Space**, **속도 1~5**를 사용합니다. 현실 시간 기준 진행 간격은 각각 2000/1000/500/250/100ms입니다(각 간격마다 게임 시간 1시간). 자정을 지날 때 기존 하루 단위 시스템을 한 번 호출합니다.
- 기사·이벤트·설정을 확인하거나 다른 화면으로 이동하면 멈춥니다. 닫은 뒤 진행 버튼으로 재개합니다. 저장을 불러올 때도 항상 일시정지하며, 실제로 자리를 비운 시간만큼 따라잡지 않습니다.
- 시작 날짜를 비우면 시작 나라의 날짜를 사용하며, 유효한 날짜가 없으면 2000-01-01로 시작합니다. 기존 시나리오 세이브는 저장된 국가 날짜에서 턴제로 복원합니다.
- **설정 › 기타 설정 › 진행 방식**은 일반 게임용입니다. 일반 게임 실시간도 같은 진행·속도 조작을 사용하지만 `worldClock`에 별도 저장합니다. 시나리오 세이브에서는 제작자가 고른 방식이 우선합니다.

```json
"time": {
  "mode": "realtime",
  "startDate": "1983-11-20",
  "startHour": 8,
  "defaultSpeed": 1
}
```

`mode`는 `turn` 또는 `realtime`, `startDate`는 비워두거나 실제 날짜(0001~9999년), `startHour`는 0~23, `defaultSpeed`는 1~5입니다. 기존 파일에서 `time`을 생략하면 턴제로 처리합니다.

## 선택형 서사 이벤트 (0.3.1)

정보 전달용 **기사**와 별도로, 이야기를 읽고 결과를 고르는 **이벤트**를 작성할 수 있습니다. **이벤트** 탭에서 제목·본문·그림을 넣고 선택지마다 표시 조건과 효과를 지정합니다. 그림을 올리면 파일에 함께 저장되며, **미리 보기**에서는 효과를 적용하지 않습니다. 프로 모드에서는 같은 데이터를 JSON으로 편집합니다.

서사 화면(`presentation: "narrative"`)은 문서형 본문 아래에 그림과 선택지를 나란히 배치합니다. 모바일에서는 세로로 배치합니다. 선택 전에는 게임 시간을 진행할 수 없고, Escape로 선택을 건너뛰지 않습니다. `presentation: "standard"`는 일반 이벤트, `super: true`는 슈퍼 이벤트를 사용합니다.

이벤트는 격변이 없어도 사용할 수 있습니다. 발생 조건이 맞으면 날짜 진행 때 자동으로 표시되고, `trigger_only: true`이면 방향성의 `event` 또는 `fire_event` 효과로 띄웁니다. 선택 효과로 플래그·변수·지지율을 바꾸거나 다음 이벤트를 연결할 수 있습니다. 대기 중인 이벤트를 저장했다 불러와도 이미 실행한 `immediate` 효과는 중복 적용하지 않습니다.

```json
{
  "id": "negotiator",
  "title": "협상가",
  "presentation": "narrative",
  "desc": "긴 대화의 첫 문단.\n\n그는 대답을 기다렸다.",
  "image": "images/negotiator.png",
  "trigger": { "date_after": "1983-11-21" },
  "options": [
    { "text": "협상을 시작한다", "effects": [{ "set_flag": "talks_started" }] },
    { "text": "지금은 때가 아니다", "effects": [] }
  ]
}
```

## 방향성 트리

- **아이콘**: 이모지 또는 그림(올리면 긴 변 최대 1024px로 줄여 `iconImage`에 담김) — 상자 위에 크게 보임
- **먼저 끝내야 함**(모두) · **이 중 하나 먼저** · **함께 못 고름**(배타, 양쪽으로) · **고를 수 있는 조건** · **끝나면 효과** · 끝나면 띄울 이벤트
- 게임에서는 한 번에 하나씩 고르고, 정한 날이 지나면 끝나 효과가 들어갑니다. 끝낸 방향성은 플래그 `focus_<id>`.

## 중점 디자인 (상자 모양)

기본은 위에 큰 아이콘(그림 · 이모지), 아래 이름판입니다. 방향성 트리 탭의 **중점 디자인**에서 상자를 통째로 다시 디자인할 수 있습니다 (시나리오의 `focusStyle`).

- `width` · `height` · `gapX` · `gapY` — 상자 크기와 간격
- `template` — 상자 속 HTML. 자리표시: `{{icon}}`(그림/이모지) `{{iconUrl}}` `{{title}}` `{{daysText}}` `{{days}}` `{{status}}` `{{statusText}}` `{{progress}}` `{{desc}}` `{{id}}`
- `css` — 방향성 트리 안에만 걸리는 CSS. 상자에는 늘 `.hf-node.hf-<상태>` (`available` · `current` · `done` · `locked` · `blocked`)
- 쓸 수 있는 태그: div · span · b · i · strong · em · small · br · p · img · u · s · sup · sub (속성은 class · style · alt · title · data-*, img는 data: 그림만). 스크립트 · 바깥 주소(url) · @import는 막힘

## 격변

- **시작**: 시작 날짜(선택)와 시작 조건 — 예: `{ "flag": "focus_f_start" }`(어떤 방향성을 끝냄). 시작하면 플래그 `crisis_<id>`가 켜지고 시작 창(그림 · 설명) 또는 "시작할 때 띄울 이벤트"가 뜹니다.
- **게이지**: 격변의 변수. 처음 값 · 최소 · 최대 · 한 달마다 변화. 효과 `{ "add_var": { "name": "tension", "value": 10 } }`로 움직이고 조건 `{ "var": { "name": "tension", "gte": 100 } }`로 봅니다.
- **기한 있는 임무**: 격변이 시작되면(또는 "나중에 시작" 조건이 맞으면) 날을 세서, 기한 안에 조건이 맞으면 성공 효과 · 못 하면 실패 효과.
- **격변 전용 이벤트 · 결정**: 그 격변이 진행 중일 때만 돕니다 (결정은 시나리오 › 격변과 국가 › 결정 탭에).
- **결말**: 위에서부터 조건이 처음 맞는 결말로 격변이 끝납니다 — 결말 창, 효과, 플래그 `crisis_<id>_<결말 id>` · `crisis_<id>_done`.

## 슈퍼 이벤트

이벤트에 `"super": true`를 넣으면 화면 가운데 큰 창으로 뜹니다. 함께 쓰는 칸: `"image"`(그림 주소 · data:), `"quote"`, `"quote_author"`, `"kicker"`(제목 위 작은 글).

## 게임에서

- 시나리오 세이브에서는 맨 위에 **시나리오** 탭(개요 · 방향성 · 격변)과 오른쪽 **시나리오** 화면(방향성 트리 · 격변)이 생깁니다.
- 시나리오 시간의 하루 진행 · 방향성 완료 시점 · 총선 결과 반영 때 방향성 진행 · 격변 시작 · 게이지 · 임무 · 결말 · 시나리오 결말을 검사합니다.
- 시나리오는 그 세이브에 저장됩니다. "시나리오 끝내기"는 나라는 그대로 두고 시나리오만 뗍니다.

## Campaign Studio 제작 흐름

### 가이드 / 프로 모드

화면 상단에서 **가이드** 또는 **프로 · JSON**을 선택합니다. 두 모드는 같은 시나리오 데이터를 편집하므로 언제든 전환할 수 있습니다.

- **가이드**: 제목, 기간, 설명을 채우고 조건·효과를 폼으로 추가합니다. 변수 이름과 수치, 비교 방식, 플래그, 날짜, 내각 지지율, 집권 세력 의석 비율 등을 고를 수 있습니다. 이벤트·결정·선택지도 폼으로 작성합니다. 조건의 플래그 칸에서 방향성 완료를 골라 자동으로 연결할 수 있습니다.
- **프로**: 방향성·격변의 항목 JSON 또는 고급 탭의 전체 JSON을 직접 편집합니다. 항목·전체 JSON은 **적용**할 때 검사하며, 실패하면 원본을 유지합니다. 적용하지 않은 JSON이 있으면 탭 이동·모드 전환·내보내기·플레이를 막아 초안 손실을 방지합니다. **JSON 변경 취소**로 마지막 적용본으로 돌아갑니다.
- 가이드가 표현할 수 없는 복합 조건·커스텀 효과는 “사용자 정의 규칙”으로 표시하며 그대로 보존합니다. 프로 모드에서 편집하세요. 기존 파일의 확장 필드도 유지됩니다.
- 저장 상태를 상단에서 확인하세요. 로컬 IndexedDB 자동 저장이며, 저장 실패 시 파일로 내보내 보관할 수 있습니다. 변경 이력은 현재 시나리오 세션 안에서 최대 60단계 실행 취소·다시 실행할 수 있습니다. 시나리오를 바꾸면 이력은 초기화됩니다.

### 첫 시나리오 만들기

기본 · 세계관의 **갈림길 시나리오으로 새로 만들기**를 누르면 기존 제작물을 보존하고 별도 시나리오를 생성합니다. 6개 방향성, 서로 배타적인 두 노선, 선택 선행 조건으로 합류하는 마지막 방향성, 사회 긴장 게이지와 기한 임무, 슈퍼 이벤트 및 결말이 포함됩니다. 예제의 시작 나라는 내장 튜토리얼 나라입니다. 자신의 `.hemi` 세이브나 다른 프리셋으로 바꾸어 사용하세요.

### 트리 작업실

1. 방향성을 선택해 제목·아이콘·기간·설명을 채웁니다.
2. **+ 방향성**은 선택한 방향성 다음에 새 중점을 추가합니다. **양갈래 분기**는 선택한 중점 아래에 서로 배타적인 두 노선을 만듭니다. **복제**는 내용·효과·선행 조건을 복사하되 배타 관계는 복사하지 않습니다.
3. 연결 도구에서 **필수 선행 / 선택 선행 / 상호 배타**를 고릅니다. 출발 중점을 선택한 뒤 대상 중점을 클릭하세요. 필수·선택 연결은 출발 → 대상이며, 같은 관계를 다시 클릭하면 해제합니다. 선택·이동으로 돌아가면 드래그할 수 있습니다. 오른쪽 칩에서는 선택한 중점의 선행 중점을 지정합니다.
4. 필수 선행은 모두 완료해야 합니다. 선택 선행은 그중 하나를 완료하면 됩니다. 배타적인 두 노선을 합류시킬 때는 선택 선행을 쓰세요. 순환 또는 불가능한 필수 연결은 검사에서 차단합니다.
5. **휠**로 마우스 위치를 기준으로 확대·축소하고, **휠 버튼을 누른 채 드래그**해 화면을 이동합니다 (방향성 위에서도 이동 가능). 빈 공간을 왼쪽 버튼으로 끌어도 이동합니다. 스크롤바는 표시하지 않습니다. 확대·축소 버튼과 전체 보기도 사용할 수 있으며, 캔버스에 포커스한 상태에서 `+`/`-`는 확대·축소, `0`은 전체 보기, 방향키는 화면 이동입니다. 편집기와 실제 플레이 화면에 같은 조작이 적용됩니다. 검색 후 Enter로 해당 중점으로 이동합니다. Tab과 Enter/Space로도 중점을 선택할 수 있습니다. **자동 정렬**은 연결 관계를 유지하면서 위치를 다시 배치합니다.
6. **일러스트 / 클래식 / 기밀 문서 / 전시 훈장** 디자인은 실제 게임에도 그대로 적용됩니다. 프로 모드에서는 기존 HTML/CSS 디자인 기능을 사용할 수 있습니다. 특정 모드의 이미지나 콘텐츠를 복제한 것은 아니며, 아이콘 그림은 직접 넣을 수 있습니다.

**검사** 버튼은 중복 ID, 잘못된 참조, 도달 불가능한 순환 연결, 배타 노선을 동시에 요구하는 필수 경로, 잘못된 데이터 형식 등을 보고합니다. 위치 겹침과 비어 있는 결말 조건은 경고로 표시합니다. 구조 검사는 실제 게임 속 모든 조건의 달성 가능성이나 이야기 균형까지 보장하지 않으므로 마지막에는 시험 플레이하세요.

방향성 ID를 바꾸면 선행·배타 연결과 `focus_<id>` 플래그 참조도 함께 변경됩니다. ID를 삭제할 때에는 플래그를 사용하는 격변·이벤트·결말도 확인하세요.

### 시작하기 (SAVE SELECT)와 만들기

시작 화면의 **시작하기 (SAVE SELECT) › 시나리오 · 챌린지**에서 메이커에 저장된 제작물을 검색하고, 새 플레이를 시작하거나 편집·삭제할 수 있습니다. 시작 나라가 여러 개인 시나리오는 나라를 고른 뒤 시작합니다. 챌린지는 제작 폼의 조건을 게임용 조건으로 변환한 뒤 시작합니다.

- **만들기**에서는 맵·시나리오·챌린지의 제작물 목록을 한 번에 보고 종류별 필터·검색·편집·삭제할 수 있습니다. 기존 제작물은 저장소를 옮기지 않고 그대로 표시됩니다.
- 새 플레이는 제작물의 복사본을 새 게임 세이브에 붙입니다. 진행 중인 게임은 **이어하기**에서 엽니다.
- 삭제는 확인 후 제작물만 영구 삭제합니다. 이미 생성된 플레이 세이브와 그 안의 시나리오·챌린지는 남습니다. 필요한 제작물은 먼저 파일로 내보내 두세요.

## 큰 방향성 일러스트

기본 트리는 작은 아이콘 슬롯 대신 **큰 일러스트 + 겹치는 명판**을 사용합니다. 그림은 노드 폭보다 넓게 펼쳐지고 명판 뒤로 겹칠 수 있습니다. 투명 PNG/WebP로 만든 합성 일러스트를 올리면 인물·건물 등의 실루엣을 그대로 표현할 수 있습니다. 업로드 시 긴 변 최대 1024px로 줄이며 투명도를 유지합니다.

- 방향성의 **그림 크기(50~200%) · 가로/세로 이동(-120~120px)**으로 배치를 조절합니다. **그림 배치 초기화**로 기본값으로 돌아갑니다.
- 트리 디자인의 **일러스트**가 새 기본값입니다. **클래식**을 선택하면 기존 124×116px의 작은 아이콘 모양을 사용합니다. 기존 HTML/CSS 사용자 템플릿과 기밀 문서·전시 훈장 디자인도 유지됩니다.
- 그림의 돌출 공간을 고려해 캔버스 여백을 잡고, 편집기와 실제 게임에서 같은 배치를 사용합니다. 큰 트리는 전체 보기·확대/축소로 탐색하세요.
- JSON에서는 방향성에 `"art": { "scale": 135, "x": 0, "y": -8 }`을 설정합니다. `focusStyle.layout`은 `"illustration"`(기본) 또는 `"classic"`입니다. `focusStyle`의 크기·간격 설정은 그대로 사용할 수 있습니다.

## 시나리오 기사 — 정보 전달용 자동 보도

**기사** 탭에서 제목 · 부제 · 신문/통신사 이름 · 본문 · 그림을 작성하고 미리 봅니다. 시나리오의 세계관과 상황을 전달하는 읽기 전용 기사이며, 기본 게임 **여론 › 기사**의 작성·발행 시스템과 별도로 동작합니다. 격변을 만들 필요가 없습니다.

발행 계기는 다음 중 하나입니다.

| 계기 | JSON | 동작 |
|---|---|---|
| 시나리오 시작 시 | `"when": "start"` | 시작 시 한 번 발행 |
| 방향성 완료 시 | `"when": "focus", "focus": "opening"` | 해당 방향성이 끝나면 발행 |
| 지정 날짜부터 | `"when": "date", "date": "2000-01-01"` | 그 날짜에 도달하거나 지난 경우 발행 |
| 조건 충족 시 | `"when": "condition", "trigger": { "flag": "news_ready" }` | 날짜 진행·총선 반영·이벤트/결정 효과 적용·시나리오 확인 시 조건 검사 |
| 방향성의 기사 연결 | `"when": "manual"` | 방향성의 `"article": "기사id"`로 연결해 완료 시 발행 |

자동 발행 계기에는 `trigger`로 추가 조건을 붙일 수 있습니다. 방향성에서 직접 연결한 기사는 완료 시 발행합니다. 모든 기사는 시나리오 세이브별로 한 번만 발행되며, 여러 건이면 순서대로 보여 줍니다. 소개·격변·이벤트 창을 닫은 뒤 다음 기사가 열립니다. **확인** 또는 Escape로 닫고 **시나리오 › 기사**에서 다시 읽을 수 있습니다. 발행 시점의 날짜와 본문(변수 치환 포함), 읽음 상태와 미확인 대기 목록도 세이브에 보존됩니다.

```json
{
  "articles": [
    {
      "id": "talks_news",
      "title": "정부, 원탁회의 소집 발표",
      "subtitle": "정국의 새로운 전환점",
      "source": "공화국 통신",
      "body": "오늘 정부는 각계 대표를 초청했습니다.\n\n긴장 수치는 {var:tension}입니다.",
      "image": "",
      "when": "focus",
      "focus": "dialogue"
    }
  ]
}
```

기사에는 선택지·효과·게이지·임무·승패가 없습니다. 게임의 여론 기사 목록과 지지율을 변경하지도 않습니다. 선택과 효과가 필요하면 **이벤트**, 격변 진행이 필요하면 **격변**을 사용하세요. 기존 스크립트의 `article` 효과는 계속 기본 게임의 여론 기사를 발행하므로 시나리오 기사와 구별해야 합니다.

`articles`가 없는 기존 시나리오도 그대로 열립니다. 갈림길 예제 시나리오에는 첫 방향성 완료로 발행되는 기사가 포함됩니다. 검사에는 `node tests/campaign-articles.test.cjs`와 기존 테스트 서버에서 `node tests/campaign-articles.browser.cjs`를 사용할 수 있습니다.

방향성 트리의 마우스 조작은 기존 테스트 서버에서 `node tests/tree-viewport.browser.cjs`로 검증합니다. 마우스 위치 기준 확대, 노드 위 휠 버튼 이동, 스크롤바 숨김, 축소 후 실제 스크롤 범위, 기존 노드 드래그와 게임 화면 새로 그리기를 검사합니다.

표시 명칭은 기존 캠페인 → 시나리오, 기존 시나리오(위기) → 격변으로 변경했습니다. 기존 제작물 호환을 위해 파일 이름, `.hemicmp`, `hemicycle-campaign@1`, `campaign`/`crises` 키와 스크립트 플래그는 유지합니다. 메이커 간 바로 이동 버튼은 삭제했으며 종류 변경은 제작물 목록에서 합니다.

## 세계지도 연동 (개발 중 · v1.7.1 / 0.3.2)

방향성·이벤트·결정이 **세계 › 지도**의 영토를 바꾸고, 바뀐 영토를 조건으로 후속 이야기를 열 수 있습니다. 설계와 결정 기록은 [시나리오·세계지도 연동 설계](design/SCENARIO_WORLD_INTEGRATION.md), 예제는 [`docs/example-scenario/border-agreement.hemicmp`](example-scenario/)(국경 협정)입니다.

### 준비

1. 게임의 **세계 › 지도**에서 `.hemimap`을 불러와 처음 영토를 칠하고 `.hemi`로 저장합니다.
2. 시나리오 메이커 **시작 나라**에서 그 세이브를 고릅니다. 내장 프리셋에는 세계지도가 없습니다.
3. 같은 탭의 **세계지도 연결**에서 이야기에 나오는 나라를 적고(열쇠 `republic` · 이름 `공화국`), 시작 나라마다 그 세이브의 실제 국가(세계 › 국가 순위의 국가)에 연결합니다.

```json
"world": { "countries": [{ "key": "republic", "name": "공화국" }, { "key": "federation", "name": "연방" }] },
"starts": [{ "id": "s1", "kind": "save", "worldBindings": { "republic": "w_republic", "federation": "w_federation" } }]
```

나라 열쇠는 이름과 따로입니다. 이름이 같아도 다른 나라를 합치지 않고, 시작 나라가 여럿이면 실제 국가 id가 달라도 같은 열쇠가 같은 나라를 가리킵니다. 게임을 시작하면 고른 시작 나라의 연결이 세이브의 `campaign.worldBindings`에 확정됩니다(이 칸이 없는 예전 세이브는 시작 나라의 선언에서 되살립니다). 이름으로 추측해 자동 연결하거나 없는 나라를 효과 실행 중에 만들지 않습니다.

### 조건과 효과

| 종류 | 열쇠 | 예 |
|---|---|---|
| 조건 | `owns_regions` — 구역 소유 | `{ "owns_regions": { "country": { "key": "republic" }, "regions": ["riverbank", "island"], "mode": "all" } }` |
| 효과 | `transfer_regions` — 영토 변경 | `{ "transfer_regions": { "regions": ["riverbank"], "to": { "key": "republic" } } }` |
| 조건 | `in_economic_region` — 경제권 소속 | `{ "in_economic_region": { "zone": { "id": "north" }, "regions": ["riverbank"], "mode": "any" } }` |
| 효과 | `assign_economic_region` — 경제권 배정 | `{ "assign_economic_region": { "regions": ["riverbank"], "to": { "id": "north" } } }` |

- `mode`는 `all`(기본 — 모두) 또는 `any`(하나 이상). 나라·경제권 자리에 `{ "unassigned": true }`를 쓰면 미배정을 뜻합니다(`key`/`id`와 함께 쓰면 오류).
- 구역은 지도의 구역 키(`district.svgMap.shapes[].key`), 경제권은 **세계 › 경제권**의 ID입니다. 가이드 입력에서는 이름으로 고릅니다.
- `all`·`any`·`not`, 플래그·변수 조건과 섞어 쓸 수 있습니다. 가이드의 조건·효과 목록에 **구역 소유 · 영토 변경 · 경제권 소속 · 경제권 배정 (세계지도)**가 있습니다.
- 이 네 가지는 **시나리오 안에서만** 동작합니다. 일반 스크립트 모드에는 나라 열쇠가 없어 조건은 거짓, 효과는 건너뜁니다.

### 실패했을 때

- 지도·나라 연결·구역·경제권이 없으면 조건은 **식 전체가 거짓**입니다. `not`이 틀린 참조를 참으로 뒤집지 않고 `any`가 없는 구역을 건너뛰지 않습니다.
- 한 효과의 구역 목록은 **전부 바뀌거나 하나도 바뀌지 않습니다.** 이미 그 나라(경제권) 것인 구역은 성공한 무변경입니다.
- 방향성 완료·결정·이벤트 선택은 효과를 실행하기 **전에** 세계지도 참조를 검사합니다(조건부 분기는 실행하지 않고 참조만 봅니다). 걸리면 방향성은 완료로 기록하지 않고, 결정은 사용 기록을 남기지 않고, 이벤트 창은 닫지 않은 채 이유를 보여 줍니다 — 고친 뒤 다시 할 수 있습니다.
- 이 원자성은 한 영토·경제권 효과의 구역 목록에 대한 것입니다. 경제·여론 등 다른 효과까지 되돌리는 전역 롤백은 없습니다. 숨은 이벤트·격변의 시작/임무 효과처럼 사전 검사를 거치지 않는 길에서는 틀린 영토 효과만 건너뛰고 모드 기록(국가 › 결정 › 모드)에 이유를 남깁니다.
- 시나리오 효과가 지도를 바꾸면 지도 화면의 수동 실행 취소 기록을 비웁니다(실행 취소로 이벤트 결과만 되돌리고 완료 기록이 남는 일 방지). 보던 위치·확대는 그대로입니다.

### 지도 변경 시 이벤트

이벤트의 **발생 조건을 검사하는 때**(`check`)에 **지도 변경 시**(`"world"`)가 추가됐습니다. `"date"`(기본)·`"election"`은 그대로이고 `"any"`는 지도 변경도 포함합니다.

- 영토나 경제권 배정이 실제로 바뀐 뒤(효과 목록이 끝난 뒤, 수동 칠하기는 붓질이 끝난 뒤) **한 번** 검사합니다. 날짜·턴을 넘기지 않고 월별 변화를 더 적용하지 않습니다.
- 같은 때 방향성 조건·격변 임무/결말·조건 기사·결말도 다시 봅니다.
- 숨은 이벤트가 서로 영토를 바꾸며 끝없이 이어지면 **32번째 검사에서 멈추고** 관련 이벤트를 알려 줍니다.

### 플레이 규칙 · 직접 수정 잠금 (개발 중)

**기본 · 세계관** 탭의 **플레이 규칙 · 직접 수정 잠금**에서 **세계지도 영토**와 **경제권**을 잠글 수 있습니다. 잠그면 플레이어는 세계 › 지도 · 경제권에서 칠하기 · 지우기 · 실행 취소 · 지도 바꾸기 · 국가 추가 · 경제권 편집을 할 수 없고(구역 확인 · 확대 · 내보내기는 됨), 영토가 있는 국가를 국가 순위에서 지울 수도 없습니다. **방향성 · 이벤트 · 결정의 효과로는 그대로 바뀝니다.** 시험 플레이에도 적용됩니다.

```json
"playRules": { "locks": { "worldMap": true, "economicRegions": true } }
```

정당 · 의석 · 선거제도 · 정부 · 경제 · 시간 같은 다른 항목의 잠금은 **아직 없습니다**(적어 두면 검사가 “적용되지 않음” 경고를 냅니다).

## 오류 검사 (개발 중 · v1.7.1 / 0.3.2)

**검사**는 결과를 **오류 / 경고 / 확인 필요**로 나눠 개수·위치(“국경 협상 › 협정을 수락한다 › 영토 변경”)·이유·JSON 경로를 보여 주고, 누르면 그 항목으로 이동합니다. 시험 플레이는 오류가 있을 때만 막고, 저장·내보내기는 오류가 있어도 됩니다.

| 단계 | 뜻 | 예 |
|---|---|---|
| 오류 | 게임이 아는 조건·효과인데 인수가 틀렸거나 없는 것을 가리킴 | 숫자가 아닌 비교 값, 없는 이벤트·결정·나라·구역·경제권, 조건 없이 반복하는 이벤트, 서로를 부르는 숨은 이벤트, 최상위와 격변 안에서 겹치는 이벤트·결정 ID, 지도 없는 시작 나라 |
| 경고 | 동작은 하지만 의도와 다를 수 있음 | 알 수 없는 조건·효과(확장 기능일 수 있어 지우지 않고 보존), 처음부터 자기 영토인 구역을 넘기는 효과, 없는 방향성의 완료 플래그 |
| 확인 필요 | 정적 검사로는 단정할 수 없음 — 시험 플레이에서 확인 | 켜는 효과가 없는 플래그, 선언하지 않은 변수, 선택에 따라 되풀이될 수 있는 이벤트 연쇄 |

조건의 `all`·`any`·`not`과 효과의 `if`(then·else)·`random_list` 안쪽까지 검사합니다. 세계지도 참조는 **고를 수 있는 모든 시작 나라**에서 유효해야 하며, 어느 시작 나라에서 틀렸는지 알려 줍니다. 새 항목이 없는 이전 시나리오는 그대로 통과합니다.

아직 하지 않는 것: 입력 중 자동(지연) 검사, 시험 플레이 중 조건 평가·효과 실패 추적 화면, 프로 JSON 편집기 안의 정확한 줄 위치로 이동(지금은 해당 탭·카드·입력 칸까지).

검증: `node --test tests/world-rules.test.cjs tests/campaign-tools.test.cjs`, 로컬 서버에서 `node tests/world-scenario.browser.cjs`.
