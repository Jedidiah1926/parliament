# Hemicycle 캠페인 · 시나리오 (0.3.0 · 테스트)

```
캠페인   — 방향성과 세계관이 있는 큰 이야기 (모드 한 벌)
 └ 시나리오(위기) — 캠페인 안의 세부 설정 (위기 하나하나)
     └ 종합 프리셋 — 나라 한 판 전체 (.hemi)
```

메인 화면 › **만들기** › **캠페인 메이커**(scenario.html)에서 만들고, ▶ 시험 플레이로 바로 게임에서 해 봅니다.
목표 · 실패 조건만 있는 짧은 도전은 [챌린지](CHALLENGE.md)(challenge.html).

## 편집기 탭

| 탭 | 내용 |
|---|---|
| 기본 · 세계관 | 제목 · 제작자 · 버전 · 한 줄 설명, 세계관 글 (캠페인을 시작할 때 크게 뜸) |
| 시작 나라 | 내장 프리셋 또는 세이브 파일(.hemi). 여러 개면 시작할 때 고름 |
| 방향성 트리 | 며칠씩 걸려 끝나는 선택. 큰 일러스트와 명판을 배치하고 연결 |
| 기사 | 방향성 완료 · 날짜 · 조건을 계기로 자동 표시되는 캠페인 전용 정보 기사 |
| 시나리오(위기) | 시작 조건 · 날짜, 게이지, 기한 있는 임무, 결말, 위기 전용 이벤트 · 결정 |
| 결말 | 캠페인의 엔딩 — 조건이 처음 맞는 것 |
| 고급 | 캠페인 내내 도는 변수 · 이벤트 · 결정 |

조건 · 효과는 [스크립트 모드](MODDING.md)와 같은 JSON입니다. 칸 옆 **+ 도우미**로 자주 쓰는 모양을 넣고 값만 고치세요.

방향성 · 위기의 세부 정보는 **칸으로**(칸 채우기) 또는 **JSON으로**(그 항목 전체를 직접) 고칠 수 있습니다 — 오른쪽 위 전환. 고급 탭의 **캠페인 전체 JSON**으로 모든 것을 한 번에 고칠 수도 있습니다 (그림 · 시작 세이브 데이터는 짧은 자리표시로 보이고 그대로 이어 붙음).

## 방향성 트리

- **아이콘**: 이모지 또는 그림(올리면 긴 변 최대 1024px로 줄여 `iconImage`에 담김) — 상자 위에 크게 보임
- **먼저 끝내야 함**(모두) · **이 중 하나 먼저** · **함께 못 고름**(배타, 양쪽으로) · **고를 수 있는 조건** · **끝나면 효과** · 끝나면 띄울 이벤트
- 게임에서는 한 번에 하나씩 고르고, 정한 날이 지나면 끝나 효과가 들어갑니다. 끝낸 방향성은 플래그 `focus_<id>`.

## 중점 디자인 (상자 모양)

기본은 위에 큰 아이콘(그림 · 이모지), 아래 이름판입니다. 방향성 트리 탭의 **중점 디자인**에서 상자를 통째로 다시 디자인할 수 있습니다 (캠페인의 `focusStyle`).

- `width` · `height` · `gapX` · `gapY` — 상자 크기와 간격
- `template` — 상자 속 HTML. 자리표시: `{{icon}}`(그림/이모지) `{{iconUrl}}` `{{title}}` `{{daysText}}` `{{days}}` `{{status}}` `{{statusText}}` `{{progress}}` `{{desc}}` `{{id}}`
- `css` — 방향성 트리 안에만 걸리는 CSS. 상자에는 늘 `.hf-node.hf-<상태>` (`available` · `current` · `done` · `locked` · `blocked`)
- 쓸 수 있는 태그: div · span · b · i · strong · em · small · br · p · img · u · s · sup · sub (속성은 class · style · alt · title · data-*, img는 data: 그림만). 스크립트 · 바깥 주소(url) · @import는 막힘

## 시나리오(위기)

- **시작**: 시작 날짜(선택)와 시작 조건 — 예: `{ "flag": "focus_f_start" }`(어떤 방향성을 끝냄). 시작하면 플래그 `crisis_<id>`가 켜지고 시작 창(그림 · 설명) 또는 "시작할 때 띄울 이벤트"가 뜹니다.
- **게이지**: 위기의 변수. 처음 값 · 최소 · 최대 · 한 달마다 변화. 효과 `{ "add_var": { "name": "tension", "value": 10 } }`로 움직이고 조건 `{ "var": { "name": "tension", "gte": 100 } }`로 봅니다.
- **기한 있는 임무**: 위기가 시작되면(또는 "나중에 시작" 조건이 맞으면) 날을 세서, 기한 안에 조건이 맞으면 성공 효과 · 못 하면 실패 효과.
- **위기 전용 이벤트 · 결정**: 그 위기가 진행 중일 때만 돕니다 (결정은 캠페인 › 위기와 국가 › 결정 탭에).
- **결말**: 위에서부터 조건이 처음 맞는 결말로 위기가 끝납니다 — 결말 창, 효과, 플래그 `crisis_<id>_<결말 id>` · `crisis_<id>_done`.

## 슈퍼 이벤트

이벤트에 `"super": true`를 넣으면 화면 가운데 큰 창으로 뜹니다. 함께 쓰는 칸: `"image"`(그림 주소 · data:), `"quote"`, `"quote_author"`, `"kicker"`(제목 위 작은 글).

## 게임에서

- 캠페인 세이브에서는 맨 위에 **캠페인** 탭(개요 · 방향성 · 위기)과 오른쪽 **캠페인** 화면(방향성 트리 · 위기)이 생깁니다.
- 날짜를 넘길 때 · 총선 결과를 반영할 때 방향성 진행 · 위기 시작 · 게이지 · 임무 · 결말 · 캠페인 결말을 검사합니다.
- 캠페인은 그 세이브에 저장됩니다. "캠페인 끝내기"는 나라는 그대로 두고 캠페인만 뗍니다.

## Campaign Studio 제작 흐름

### 가이드 / 프로 모드

화면 상단에서 **가이드** 또는 **프로 · JSON**을 선택합니다. 두 모드는 같은 캠페인 데이터를 편집하므로 언제든 전환할 수 있습니다.

- **가이드**: 제목, 기간, 설명을 채우고 조건·효과를 폼으로 추가합니다. 변수 이름과 수치, 비교 방식, 플래그, 날짜, 내각 지지율, 집권 세력 의석 비율 등을 고를 수 있습니다. 이벤트·결정·선택지도 폼으로 작성합니다. 조건의 플래그 칸에서 방향성 완료를 골라 자동으로 연결할 수 있습니다.
- **프로**: 방향성·위기의 항목 JSON 또는 고급 탭의 전체 JSON을 직접 편집합니다. 항목·전체 JSON은 **적용**할 때 검사하며, 실패하면 원본을 유지합니다. 적용하지 않은 JSON이 있으면 탭 이동·모드 전환·내보내기·플레이를 막아 초안 손실을 방지합니다. **JSON 변경 취소**로 마지막 적용본으로 돌아갑니다.
- 가이드가 표현할 수 없는 복합 조건·커스텀 효과는 “사용자 정의 규칙”으로 표시하며 그대로 보존합니다. 프로 모드에서 편집하세요. 기존 파일의 확장 필드도 유지됩니다.
- 저장 상태를 상단에서 확인하세요. 로컬 IndexedDB 자동 저장이며, 저장 실패 시 파일로 내보내 보관할 수 있습니다. 변경 이력은 현재 캠페인 세션 안에서 최대 60단계 실행 취소·다시 실행할 수 있습니다. 캠페인을 바꾸면 이력은 초기화됩니다.

### 첫 캠페인 만들기

기본 · 세계관의 **갈림길 캠페인으로 새로 만들기**를 누르면 기존 제작물을 보존하고 별도 캠페인을 생성합니다. 6개 방향성, 서로 배타적인 두 노선, 선택 선행 조건으로 합류하는 마지막 방향성, 사회 긴장 게이지와 기한 임무, 슈퍼 이벤트 및 결말이 포함됩니다. 예제의 시작 나라는 내장 튜토리얼 나라입니다. 자신의 `.hemi` 세이브나 다른 프리셋으로 바꾸어 사용하세요.

### 트리 작업실

1. 방향성을 선택해 제목·아이콘·기간·설명을 채웁니다.
2. **+ 방향성**은 선택한 방향성 다음에 새 중점을 추가합니다. **양갈래 분기**는 선택한 중점 아래에 서로 배타적인 두 노선을 만듭니다. **복제**는 내용·효과·선행 조건을 복사하되 배타 관계는 복사하지 않습니다.
3. 연결 도구에서 **필수 선행 / 선택 선행 / 상호 배타**를 고릅니다. 출발 중점을 선택한 뒤 대상 중점을 클릭하세요. 필수·선택 연결은 출발 → 대상이며, 같은 관계를 다시 클릭하면 해제합니다. 선택·이동으로 돌아가면 드래그할 수 있습니다. 오른쪽 칩에서는 선택한 중점의 선행 중점을 지정합니다.
4. 필수 선행은 모두 완료해야 합니다. 선택 선행은 그중 하나를 완료하면 됩니다. 배타적인 두 노선을 합류시킬 때는 선택 선행을 쓰세요. 순환 또는 불가능한 필수 연결은 검사에서 차단합니다.
5. 빈 공간을 끌어 화면을 이동하고, 확대·축소 또는 전체 보기로 큰 트리를 탐색합니다. 검색 후 Enter로 해당 중점으로 이동합니다. Tab과 Enter/Space로도 중점을 선택할 수 있습니다. **자동 정렬**은 연결 관계를 유지하면서 위치를 다시 배치합니다.
6. **일러스트 / 클래식 / 기밀 문서 / 전시 훈장** 디자인은 실제 게임에도 그대로 적용됩니다. 프로 모드에서는 기존 HTML/CSS 디자인 기능을 사용할 수 있습니다. 특정 모드의 이미지나 콘텐츠를 복제한 것은 아니며, 아이콘 그림은 직접 넣을 수 있습니다.

**검사** 버튼은 중복 ID, 잘못된 참조, 도달 불가능한 순환 연결, 배타 노선을 동시에 요구하는 필수 경로, 잘못된 데이터 형식 등을 보고합니다. 위치 겹침과 비어 있는 결말 조건은 경고로 표시합니다. 구조 검사는 실제 게임 속 모든 조건의 달성 가능성이나 이야기 균형까지 보장하지 않으므로 마지막에는 시험 플레이하세요.

방향성 ID를 바꾸면 선행·배타 연결과 `focus_<id>` 플래그 참조도 함께 변경됩니다. ID를 삭제할 때에는 플래그를 사용하는 위기·이벤트·결말도 확인하세요.

### 시작하기 (SAVE SELECT)와 만들기

시작 화면의 **시작하기 (SAVE SELECT) › 캠페인 · 챌린지**에서 메이커에 저장된 제작물을 검색하고, 새 플레이를 시작하거나 편집·삭제할 수 있습니다. 시작 나라가 여러 개인 캠페인은 나라를 고른 뒤 시작합니다. 챌린지는 제작 폼의 조건을 게임용 조건으로 변환한 뒤 시작합니다.

- **만들기**에서는 맵·캠페인·챌린지의 제작물 목록을 한 번에 보고 종류별 필터·검색·편집·삭제할 수 있습니다. 기존 제작물은 저장소를 옮기지 않고 그대로 표시됩니다.
- 새 플레이는 제작물의 복사본을 새 게임 세이브에 붙입니다. 진행 중인 게임은 **이어하기**에서 엽니다.
- 삭제는 확인 후 제작물만 영구 삭제합니다. 이미 생성된 플레이 세이브와 그 안의 캠페인·챌린지는 남습니다. 필요한 제작물은 먼저 파일로 내보내 두세요.

## 큰 방향성 일러스트

기본 트리는 작은 아이콘 슬롯 대신 **큰 일러스트 + 겹치는 명판**을 사용합니다. 그림은 노드 폭보다 넓게 펼쳐지고 명판 뒤로 겹칠 수 있습니다. 투명 PNG/WebP로 만든 합성 일러스트를 올리면 인물·건물 등의 실루엣을 그대로 표현할 수 있습니다. 업로드 시 긴 변 최대 1024px로 줄이며 투명도를 유지합니다.

- 방향성의 **그림 크기(50~200%) · 가로/세로 이동(-120~120px)**으로 배치를 조절합니다. **그림 배치 초기화**로 기본값으로 돌아갑니다.
- 트리 디자인의 **일러스트**가 새 기본값입니다. **클래식**을 선택하면 기존 124×116px의 작은 아이콘 모양을 사용합니다. 기존 HTML/CSS 사용자 템플릿과 기밀 문서·전시 훈장 디자인도 유지됩니다.
- 그림의 돌출 공간을 고려해 캔버스 여백을 잡고, 편집기와 실제 게임에서 같은 배치를 사용합니다. 큰 트리는 전체 보기·확대/축소로 탐색하세요.
- JSON에서는 방향성에 `"art": { "scale": 135, "x": 0, "y": -8 }`을 설정합니다. `focusStyle.layout`은 `"illustration"`(기본) 또는 `"classic"`입니다. `focusStyle`의 크기·간격 설정은 그대로 사용할 수 있습니다.

## 캠페인 기사 — 정보 전달용 자동 보도

**기사** 탭에서 제목 · 부제 · 신문/통신사 이름 · 본문 · 그림을 작성하고 미리 봅니다. 캠페인의 세계관과 상황을 전달하는 읽기 전용 기사이며, 기본 게임 **여론 › 기사**의 작성·발행 시스템과 별도로 동작합니다. 위기를 만들 필요가 없습니다.

발행 계기는 다음 중 하나입니다.

| 계기 | JSON | 동작 |
|---|---|---|
| 캠페인 시작 시 | `"when": "start"` | 시작 시 한 번 발행 |
| 방향성 완료 시 | `"when": "focus", "focus": "opening"` | 해당 방향성이 끝나면 발행 |
| 지정 날짜부터 | `"when": "date", "date": "2000-01-01"` | 그 날짜에 도달하거나 지난 경우 발행 |
| 조건 충족 시 | `"when": "condition", "trigger": { "flag": "news_ready" }` | 날짜 진행·총선 반영·이벤트/결정 효과 적용·캠페인 확인 시 조건 검사 |
| 방향성의 기사 연결 | `"when": "manual"` | 방향성의 `"article": "기사id"`로 연결해 완료 시 발행 |

자동 발행 계기에는 `trigger`로 추가 조건을 붙일 수 있습니다. 방향성에서 직접 연결한 기사는 완료 시 발행합니다. 모든 기사는 캠페인 세이브별로 한 번만 발행되며, 여러 건이면 순서대로 보여 줍니다. 소개·위기·이벤트 창을 닫은 뒤 다음 기사가 열립니다. **확인** 또는 Escape로 닫고 **캠페인 › 기사**에서 다시 읽을 수 있습니다. 발행 시점의 날짜와 본문(변수 치환 포함), 읽음 상태와 미확인 대기 목록도 세이브에 보존됩니다.

```json
{
  "articles": [
    {
      "id": "talks_news",
      "title": "정부, 원탁회의 소집 발표",
      "subtitle": "정국의 새로운 전환점",
      "source": "공화국 통신",
      "body": "오늘 정부는 각계 대표를 초청했습니다.\n\n긴장 수치는 {var:tension}입니다.",
      "image": "",
      "when": "focus",
      "focus": "dialogue"
    }
  ]
}
```

기사에는 선택지·효과·게이지·임무·승패가 없습니다. 게임의 여론 기사 목록과 지지율을 변경하지도 않습니다. 선택과 효과가 필요하면 **이벤트**, 위기 진행이 필요하면 **시나리오(위기)**를 사용하세요. 기존 스크립트의 `article` 효과는 계속 기본 게임의 여론 기사를 발행하므로 캠페인 기사와 구별해야 합니다.

`articles`가 없는 기존 캠페인도 그대로 열립니다. 갈림길 예제 캠페인에는 첫 방향성 완료로 발행되는 기사가 포함됩니다. 검사에는 `node tests/campaign-articles.test.cjs`와 기존 테스트 서버에서 `node tests/campaign-articles.browser.cjs`를 사용할 수 있습니다.
